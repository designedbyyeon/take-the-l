# L을 가져가 (Take the L)

**설치 페이지: https://designedbyyeon.github.io/take-the-l/**

화면의 모든 영문 **L**을 폰트·크기·색·그림자 그대로 한 장씩 캡쳐해서(뷰파인더 → 찰칵 → 날아감) 옆 패널에 L 상자로 진열하고, 손바닥 위에 마지막 L을 올려 줍니다.

| 파일 | 역할 |
| --- | --- |
| `takethel.js` | 본체. 북마클릿 · 크롬 확장 · `<script>` 어디서든 같은 코드 |
| `index.html` | 설치 페이지 (시안 포스터, 북마클릿 생성, 기기별 안내) |
| `source/` | 디자인 원본 (`design.ai` 시안, `hand` 손 이미지) |
| `audio.mp4`, `assets/` | 음원, 그리고 시안에서 뽑은 `logo.svg` · `hand.webp`(페이지용) · `hand-sm.webp`(패널 내장용) |
| `build.py` | 음원·로고·손 이미지를 `takethel.js`에 내장하고 `index.html` 로고를 갱신 |
| `manifest.json`, `background.js` | 크롬 계열 확장 (이 폴더 또는 `take-the-l-extension.zip`을 풀어 “압축해제된 확장 프로그램 로드”) |

## 기기별 사용

- **맥북** — 설치 페이지를 열고 노란 버튼을 북마크 바로 드래그. 또는 크롬 확장으로 로드 (`Alt+Shift+L`).
- **아이패드 / 아이폰 (Safari)** — 아무 페이지나 북마크 → 설치 페이지의 “코드 복사” → 북마크 편집에서 주소 칸에 붙여넣기.
- **안드로이드 (Chrome)** — 같은 방식으로 북마크 URL을 바꾼 뒤, 사이트에서 주소창에 북마크 이름을 입력하고 북마크 항목을 탭.

설치 페이지는 GitHub Pages로 배포돼요. `main` 브랜치에 푸시하면 몇 분 뒤 반영됩니다.

## 패널

▶ 재생/멈춤 · 🔊 소리 · ⇄ 위치(좌/우, 폰은 위/아래) · ⬇ PNG 저장(모바일은 공유 시트) · ↺ L 돌려주기 · ✕ 닫기(돌려주고 종료).

## 음원

`audio.mp4`가 `takethel.js` 안에 base64로 내장돼 있어서(약 146KB) 어느 사이트에서든 따로 호스팅 없이 재생되고, 끊김 없이 반복됩니다. 멈춤·음소거 후 다시 켜면 항상 처음부터 재생돼요. 음원이나 `assets/`의 로고·손 이미지를 바꾸려면 파일을 교체하고:

```bash
python3 build.py
```

## 한계

이미지·`<canvas>` 속 글자, 입력창, 다른 출처 iframe 안의 L은 건드리지 않습니다. CSP가 엄격한 일부 사이트(GitHub 등)는 북마클릿 실행 자체를 막으니 확장을 쓰세요. 이미지는 최대 1500개까지 쌓고 나머지는 숫자로만 셉니다.
