L만큼 좋아!

아무 웹페이지에서 누르면 노래가 나오면서, 화면 속 영문 L을 하나씩 찰칵 찍어 손바닥 위에 올려 드려요. 폰트, 크기, 색까지 그대로. 맥북 · 아이패드 · 안드로이드 다 돼요.

설치하기

북마크 하나면 끝
  1. 북마크 바를 켜세요. Chrome · Safari 모두 ⌘⇧B
  2. 이 버튼을 북마크 바로 끌어다 놓기
    L을 가져가
  3. 아무 웹사이트에서 북마크 클릭 → 패널의 ▶ 전부 가져가기

Safari에서 안 되면: 설정 → 고급 → “웹 개발자용 기능 보기” 켠 뒤, 개발자 메뉴 → “스마트 검색 필드에서 JavaScript 허용”을 켜세요.

  1. Safari에서 지금 이 페이지를 북마크하세요. 공유 버튼 → 북마크 추가, 이름은 L을 가져가
  2. 아래 코드를 복사하세요.
  3. 책갈피 목록 → 편집 → 방금 만든 북마크 → 주소 칸을 지우고 붙여넣기 → 완료
  4. 아무 사이트에서 책갈피 목록 → L을 가져가 탭 → 패널에서 ▶ 전부 가져가기

아이패드 가로 화면에선 오른쪽, 세로 화면과 아이폰에선 아래쪽에 패널이 떠요. ⇄ 버튼으로 반대편으로 옮길 수 있어요.

  1. Chrome에서 이 페이지를 북마크하세요. ⋮ → ☆
  2. 아래 코드를 복사하세요.
  3. ⋮ → 북마크 → 방금 만든 북마크 길게 누르기 → 수정 → 이름을 takeL로, URL 칸에 붙여넣기
  4. 아무 사이트에서 주소창에 takeL 입력 → 목록에 뜨는 ☆ 북마크 항목을 탭 (엔터 말고 항목을 눌러야 해요)

Samsung Internet도 같은 방식으로 북마크 URL만 바꾸면 돼요.

  1. 확장 파일을 받아 압축을 푸세요.
    확장 파일 받기 (.zip)
  2. Chrome(또는 Edge, Arc, Whale)에서 chrome://extensions 열기 → 오른쪽 위 개발자 모드 켜기
  3. 압축해제된 확장 프로그램을 로드 → 압축을 푼 take-the-l 폴더 선택
  4. 툴바의 확장 아이콘을 누르면 실행. 단축키 AltShiftL

북마클릿이 막히는 사이트(GitHub처럼 보안이 엄격한 곳)에서도 확장은 동작해요.

궁금한 것

가져가기 전에 읽어 주세요
가져간 L은 어떻게 돌려받나요?
패널의 ↺ 를 누르면 제자리로 돌아오고, ✕ 로 닫아도 모두 돌아와요. 페이지 원본은 바뀌지 않아요.
모은 L을 저장할 수 있나요?
⬇ 버튼으로 이 포스터처럼 생긴 PNG 한 장으로 저장돼요. 아이패드 · 안드로이드에선 공유 시트가 떠서 사진 앱에 바로 넣을 수 있어요.
안 잡히는 L도 있나요?
이미지 속 글자, <canvas>로 그린 글자, 입력창 안의 글자, 다른 사이트를 띄운 iframe 안의 글자는 건드리지 않아요.
